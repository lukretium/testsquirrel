Agentic coding changes everything

Code is abundant.
Clarity is not.

AI agents can produce thousands of lines of code before a human finishes a review. But speed does not answer the essential question: what is the software supposed to do? The faster implementation becomes, the more valuable a precise specification becomes.

A new software primitive

The specification is the product. The code is just a build artifact.

Code can be regenerated, refactored, rewritten and optimized. Tomorrow’s software will be built again and again by AI.

What must remain stable is human intent: understandable, reviewable and executable for every agent that touches the product.

Test First. Still Right.

Agents need a definition of done.

Agentic coding does not make test-first development obsolete. It makes it essential. Without an executable specification, an AI agent has nothing reliable to optimize against. Without tests, every iteration is another guess.

Give the agent a target it can prove—not a prompt it can interpret.
